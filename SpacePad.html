About

Two tools here: turn any file or text into a data:/blob: link, or run text/code through a conversion (Base64, JSON, case, etc.) — search or pick a chip below to find one.

Notes

Everything runs locally in your browser, fully offline — nothing is uploaded. The data:/blob: tool accepts any file, including images. Every other conversion reads its input as text, so it's meant for code, markup, and plain text rather than binary files.

Encrypt / Decrypt AES-256-GCM

Password-based encryption using the Web Crypto API — PBKDF2 derives the key from your passphrase, and AES-GCM encrypts with a random salt and IV each time, bundled into the output so only the passphrase is needed to decrypt.

Run from URL HTML / Python

Paste a link to a raw HTML or Python file — a jsDelivr link (cdn.jsdelivr.net/gh/user/repo@branch/file), a GitHub raw link, or any URL that allows cross-origin requests. Spacepad fetches it, figures out which kind of file it is, and runs it: HTML opens live in a new tab, Python runs right here using the same runtime as the Python tab.
